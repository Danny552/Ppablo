##  Español

### Qué es esto

Este repositorio contiene el sitio web personal y académico del **Dr. Pedro Pablo Cárdenas Alzate**, matemático, investigador y profesor de la Universidad Tecnológica de Pereira (UTP). Su trabajo se mueve entre dos mundos que a primera vista parecen lejanos: la **modelación matemática de enfermedades** (virología matemática) y el **planeamiento de sistemas eléctricos de alta potencia**.

El sitio es su vitrina: un lugar donde se concentra lo que ha investigado, enseñado y publicado, sin tener que rebuscar entre perfiles dispersos.

🌐 **Sitio en vivo:** [ppablo.com.co](https://ppablo.com.co)

### Qué encontrarás en el sitio

| Sección | Contenido |
|---|---|
| **Inicio** | Presentación, último libro, reconocimientos y novedades destacadas |
| **Sobre mí** | Trayectoria académica y profesional |
| **Investigación** | Líneas de trabajo y proyectos |
| **GEDNOL** | Página del grupo de investigación |
| **Artículos** | Publicaciones científicas |
| **Libros** | Obras publicadas, entre ellas *Analyse fonctionnelle, une introduction* |
| **Docencia** | Cursos y labor docente |
| **Hobbies y más** | El lado menos formal del profe |

### Estructura del repositorio

El sitio está construido con páginas HTML estáticas, una por sección, y un directorio `assets/` con las imágenes, el CV y los folletos que se enlazan desde las páginas.

```
├── index.html        # Inicio
├── about.html        # Sobre mí
├── research.html     # Investigación
├── gednol.html       # Grupo GEDNOL
├── articles.html     # Artículos
├── books.html        # Libros
├── teaching.html     # Docencia
├── hobbies.html      # Hobbies y más
└── assets/           # Imágenes, CV (PDF), folletos
```

##  English

### What is this

This repository holds the personal and academic website of **Dr. Pedro Pablo Cárdenas Alzate**, mathematician, researcher, and professor at the Universidad Tecnológica de Pereira (UTP) in Colombia. His work lives across two worlds that seem far apart at first glance: the **mathematical modeling of disease** (mathematical virology) and the **planning of high-power electrical systems**.

The site is his showcase: one place that gathers what he has researched, taught, and published, so nobody has to dig through scattered profiles to find it.

🌐 **Live site:** [ppablo.com.co](https://ppablo.com.co)

### What you'll find on the site

| Section | Content |
|---|---|
| **Home** | Introduction, latest book, awards, and highlighted news |
| **About me** | Academic and professional background |
| **Research** | Lines of work and projects |
| **GEDNOL** | Research group page |
| **Articles** | Scientific publications |
| **Books** | Published works, including *Analyse fonctionnelle, une introduction* |
| **Teaching** | Courses and teaching work |
| **Hobbies & more** | The less formal side of the professor |

### Repository structure

The site is built from static HTML pages, one per section, plus an `assets/` directory with the images, CV, and flyers linked from those pages.
